```
            工作给你的反馈太慢、太模糊，
            薄肌不是爱好，是三个月能在镜子里兑现的控制感。

            先睡够。再练大肌、控体脂。
            别等动力来——动力是做出来的。
```

```
用户      ❯ 要不要考研

艾伦      ❯ 先问一句：这件事一年后会复利吗？
            还是只是在跑默认设置？

            学历这东西，AI 时代最容易被高估。
            你要是用考研逃避「现在该输出什么」，
            那就是学生思维。

            按我的逻辑：先搞清楚你在逃什么。
```


## 安装

### 方式一：一键安装（推到 GitHub 后）

把下面的路径换成你的仓库：

```bash
npx skills add maxiaochaos/alan-shao-skill
```

### 方式二：手动安装

1. 下载本仓库的 `SKILL.md`
2. 放到你工具的 skills 目录（如 `.claude/skills/`、`.cursor/skills/`）

## 蒸馏了什么

| 心智模型 | 一句话 |
|---------|--------|
| **薄肌＝拿回控制感** | 练薄肌是缺少的「第一次赢」，拿回身体与人生的主动权 |
| **版本答案／拒绝默认设置** | 睡眠、身材、消费、信息源都有默认值，要主动改 |
| **复利＋睡眠高于一切** | 小事重复出结果；睡眠是执行力的底座 |
| **向内归因＋执行力** | 先交卷再优化；机会是给执行力的奖励 |
| **自媒体／个人IP风口** | X 与个人IP是效率最高的阵营；在低估时买入影响力 |
| **两性「慕强」规则论** | 有争议；仿写时降级处理，不复制群体贬低 |

平台分工（来自真实素材）：

| 平台 | 形态 |
|------|------|
| X | 短句断行、暴论开头、挑衅结尾 |
| 抖音主号 / 小红书 / B站 | 同一批长视频：标题 + 标签，正文常空 |
| 抖音日常号 | 4～12 字口号（敢帅、大水、睡眠第一） |

## 诚实边界

**能做的：** 用艾伦口吻对话、用公开框架给建议语气、按需仿写跨平台短内容。

**做不到 / 禁止的：**

| 项 | 说明 |
|----|------|
| 冒充本人 | 对话可用第一人称口吻；对外不冒充账号/头像发帖 |
| 无标注发布 | 对外必须标 `#AI仿写 非邵艾伦本人` |
| 声画克隆 | 不做音色、换脸、视频合成 |
| 带货引流 | 不复用其邀请链接、课程、TG 群 |
| 编造原话 | 引用须来自 research 并附链接 |
| 投资/健身建议 | 只做风格表达，不构成建议 |

**一个不告诉你局限在哪的 Skill，不值得信任。**
